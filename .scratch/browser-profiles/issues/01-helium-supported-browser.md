# 01: Helium as a supported browser

**What to build:** Helium is treated like the other Chromium browsers: when it's a Watched App, Wabbit can ask for Automation permission and read its front tab's address, so Project addresses work in Helium. See `../spec.md`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Helium appears with the Browser addresses permission row in Watched Apps
- [ ] With permission, a Project address matches a Helium tab and the prompt suggests that Project
- [ ] Needs a human: allow Helium, open a Project's address, check the prompt
